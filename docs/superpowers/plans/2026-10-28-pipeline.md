# Pipeline (sub-plan A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development or superpowers:executing-plans to work through this plan task by task. Steps use `- [ ]` checkboxes.

**Goal:** turn the public StillDrawn release into the explorer's versioned JSON data contract. Every number is reproduced against the paper's own outputs before anything is drawn.

**Architecture:**
- A small Python package (`pipeline/stilldrawn_web`) reads a local copy of the public release. The path comes from `STILLDRAWN_ROOT`, defaulting to `~/projects/stilldrawn`.
- It writes `web/public/data/v1/*.json`, plus fixtures for the web app's parity tests.
- Media derivation and upload (task 7) wait for the R2 bucket.

**Tech stack:** Python 3.12, uv, numpy, PyYAML, pytest. boto3 is added only in task 7.

## Facts the tests pin (checked 28 Oct)

- 373 clips: primary 164, FLINT 6, repeat 98, ground 25, hazard 71, Seedance 9. Every clip has an mp4, a motion JSON and a row in `CLIP-HASHES.csv`.
- Clip id grammar: `<panel>_<idle|burst|campush>_<suffix>[-r2|-hN]` or `flint-<a>--<b>_<suffix>`. The suffixes `gen4t`, `gen45`, `h3`, `wan22`, `ltx23` and `sd2` map to the engine directories `gen4_turbo`, `gen4.5`, `h3-fal`, `wan22`, `ltx23` and `seedance`.
- Headlines follow `analysis/build_table.py`:
  - line = `line_drift.vs_frame0.chamfer_px.mean`
  - tone = `tone_spectral_drift.variance` (may be null)
  - edge = `edge_decay.abs_slope_norm`
  - style = `style_drift.terminal` (null on error)
  - closure = `|closure_proxy.drift_terminal|`
- The basis for lenses is the primary arm (standard cells only): 33 per engine, except Gen-4 Turbo at 32. Turbo's `cu-tone-3_idle_gen4t` was refused by moderation.
- Goldens come from `analysis/out/motion_confound.json`:
  - ρ(motion, drift) across engines is 0.9, with p = 1/12
  - the front is {gen4.5, gen4_turbo, ltx23, wan22}, and H3 is dominated by gen4.5
  - 8 pairs overlap, 5 are usable (n ≥ 5 each), and 2 reverse the league (h3 > gen4_turbo, ltx23 > gen4_turbo)
- Human check (`analysis/human_check/human_check_results.json`): ordinal α is 0.209 for register and 0.478 for sameness.
