# Sub-plan D: the masked-drift view (P46 Phase 7, 9.3, 10.1, 12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. **Dispatch every task with the model and effort on its Run line.** Run commands from the worktree root (`~/projects/worktrees/stilldrawn-explorer/p46-masked`) unless a step says otherwise. Nothing here pushes, deploys or touches the live site; those are Gates F, G and H (Aaron's word).

**Goal:** `/tax/masked` shows A9 for what it is, exploratory and post-hoc: Test 2 (does Gen-4.5's gap to Wan 2.2 shrink when drift is measured only where the prompt lets the drawing move?) and Test 1 (do the steadiest engines fail to do the requested motion?), from one lazily loaded contract file, built and tested against synthetic fixtures now and refreshed from the release's real A9 outputs later with one command.

**Architecture:**
- `pipeline/stilldrawn_web/masked.py` only **re-shapes** the release's A9 outputs into `web/public/data/v1/masked.json`; it computes no statistic (a test proves every numeric leaf of the statistics blocks occurs in the source JSON).
- `loadMasked()` is its own cached promise, never part of `loadCore`; the view suspends on it. `index.json` gains `masked: boolean`, so links and the route exist only when the real file does.
- `maskedModel.ts` holds every decision as a pure function (state, headline sentence, verdict copy, league rows, mask geometry); `Masked.tsx` draws.
- Fixtures are synthetic and generated by the registered scripts' own test helpers (Task 1). They never sit under `web/public/data/`; e2e serves them through route interception.

**Tech stack:** Python 3.12, uv, pytest (pipeline); React 19, Vite 8, TypeScript 7, Vitest 5 (no globals; `afterEach(cleanup)`), Playwright 1.64; d3-scale for the slopegraph.
