# Phase 6 films: implementation plan

> **For agentic workers:** executed inline (superpowers:executing-plans) in the session that wrote it. Steps use checkbox (`- [ ]`) syntax. Spec: `docs/superpowers/specs/2026-10-29-films-design.md`.

**Goal:** scripted, reproducible capture and edit for the P01 (about 80 s) and P10 (45 s) films, in 16:9 and 9:16, silent, captioned, every figure from the data contract.

**Architecture:**
- A Playwright spec records each beat as timed JPEG frames from the production build, with marks for what is on screen.
- A Python standard-library build fills caption templates from `facts.json`, and has Playwright render caption, chip and card PNGs in the explorer's face.
- ffmpeg resamples, overlays, concatenates and exports.

**Tech stack:**
- @playwright/test 1.64.1 (the explorer's pin)
- Python 3 standard library, `unittest`
- ffmpeg 9.0.2 (local; no libass or freetype: overlays are PNGs)

## File map

| Path | Responsibility |
|---|---|
| `film/README.md` | How to remake a cut (the three commands), what is gitignored |
| `film/build/facts.py` | Reads the contract and writes `film/build/out/facts.json`: every figure a caption may quote, formatted. `check_caption(text, facts)` raises on a digit run that isn't a fact or an allowed token |
| `film/build/test_facts.py` | unittest: goldens (0.96, 7.58, 0.27, 11.04, 0.90, 0.083, 1.23, 1.27, 0.21, 0.48), and that `check_caption` rejects "9.9 px" |
| `film/build/films.json` | The edit decision list: per film, per aspect, beats → segments (capture dir, in/out s, speed), captions (template, start, end), chips, cards |
| `film/build/overlay.html` | One page that renders a caption band, a chip, a badge or a full card from URL-hash JSON, in Schibsted Grotesk with the explorer's tokens |
| `film/build/render-overlays.mjs` | Renders each overlay in `out/overlays.json` to a PNG (transparent except cards) at the film's size |
| `film/build/terminal.html` | A terminal page that replays a recorded transcript (`film/build/setup-transcript.json`) at a set speed |
| `film/build/record-setup.mjs` | Runs `npm run setup` in a fresh clone (scratch dir) and writes the transcript: chunks with times, paths replaced by `~/blindpanel`; stops when the server prints its address |
| `film/build/edit.py` | frames + times → 30 fps segments; trims, speeds, overlays, concat; exports both aspects, SRT, poster, loop, contact sheets; prints the ffprobe report |
| `web/e2e/film/recorder.ts` | `Recorder(page, dir)`: `start()`, `mark(name, data)`, `stop()`; JPEG q95 screenshots at device pixels in a loop; `times.json`, `events.json` |
| `web/e2e/film/pointer.ts` | `addPointer(page)`: an init script drawing the cursor (desktop) or tap ring (touch) from real pointer events |
| `web/e2e/film/guard.ts` | `guardApi(page)`: tally → empty mock; submit → abort and record; `assertNoSubmit()` |
| `web/e2e/film.spec.ts`, `web/e2e/film.config.ts` | The beats as tests; projects `film-desktop` (1440×810 @4/3) and `film-phone` (390×563 @1080/390, touch, isMobile); baseURL `FILM_URL` |
| `.gitignore` | adds `film/capture/`, `film/out/`, `film/build/out/` |
